01 核心结论与研究范围

核心观点：炉石的长期体验，来自局内策略选择、局外卡组获取与版本更新三者的配合。数值设计既要控制强度，也要维护玩家尝试策略的意愿。

本案例以国服移动端的标准构筑为主，讨论核心循环、卡牌平衡、资源经济与活动系统；酒馆战棋只作模式分工与近期更新的补充。炉石支持电脑、手机和平板进度互通，因此移动端拆解要同时考虑共用规则和手机操作条件。官方产品介绍

三个值得面试展开的判断

  • 单卡增强可能导致体系削弱。 当数值同时参与卡池筛选，修改攻击力就可能改变组合的可获得性。评估对象应从单卡扩展到整条联动链。
  • 经济成本应落到可用卡组。 玩家需要的是能参与目标玩法的一套牌；金币、卡包和卡牌数量只是中间资源。相同奖励对不同收藏进度的玩家价值不同。
  • 移动端可以优先降低理解成本。 在共用对战规则下，帮助回归玩家理解“我的卡组为何变化、有哪些选择”，比贸然改动全服卡牌更适合作为独立系统提案。

02 核心循环与系统分工

从一局对战到一个版本

选择职业和构筑 → 匹配对局 → 分配法力与卡牌 → 获得结果和奖励 → 调整卡组 → 再次对战。 新卡与平衡补丁改变可选策略，使玩家重新进入构筑和学习阶段。

局内的乐趣来自机会成本：本回合使用资源建立场面，意味着放弃某些后续选择；留牌等待组合，意味着承受当前的进攻压力。局外的资源系统则影响玩家能否实际尝试这些选择。

系统玩家要做的决定设计价值主要风险
法力与费用当前使用还是等待组合控制强牌时点和回合节奏减费叠加可能绕过时间成本
手牌与牌库消耗、补充或保留关键牌建立资源管理和构筑取舍补牌过强可能压低消耗战价值
随从场面交换随从还是攻击英雄让收益持续暴露在对手反制下即时爆发过强可能削弱场面作用
收藏与制作专精一个体系还是拓展职业提供长期目标和尝试空间错误投入可能增加换牌压力
排名与任务追求胜率还是完成阶段目标给对战赋予持续目标任务可能诱导偏离正常对战
新卡与补丁继续精通旧牌还是学习新牌更新策略空间变化过快可能提高回归门槛

不同玩家需要不同的资源路径

新玩家首先需要理解“怎样赢”和形成一套能使用的牌；回归玩家需要恢复对卡池与规则的理解；稳定竞技玩家关心对局质量和多套牌的切换；收藏玩家还会关注外观与完整度。这是分析分组，不是已验证的用户占比。

构筑要求玩家管理自己的牌库，酒馆战棋提供无需预先组牌的入口。两者都属于炉石，但经济和平衡指标不同，不能把战棋排名、构筑胜率与卡牌收藏成本混为一个模型。官方模式说明

系统评价应看闭环

“奖励很多”不能独立证明系统有效。更有解释力的链条是：玩家获得资源后，是否形成目标卡组；是否愿意使用；是否继续进行有效对局。某环节没有发生，资源发放量就无法直接转化为玩法参与。

03 数值分析应先确定场景

单卡强度没有脱离环境的固定分数

评估卡牌时至少看五个方面：生效回合、立即收益、持续收益、达成条件和被反制方式。费用、攻击与生命决定一部分价值，战吼、亡语、检索和复制会改变兑现方式。职业可用的配套卡也会改变同一效果的实际强度。

示例一：一费变化为什么不等价。 假设一个组合由5费启动牌和2费配合牌组成，不考虑减费与额外资源时，需要7点可用法力；启动牌加到6费后，门槛变为8点。它既可能晚一个回合，也可能无法再与其他2费行动一起完成。因此，不能仅用“费用增加20%”描述削弱幅度。

示例二 关键牌投入量与稳定性

以下为简化抽样模型：30张牌库，关键牌放入1张或2张；不换牌、不检索、不额外抽牌，把已见到的n张视为等概率无放回抽样。它不等同于某一具体回合的实战概率。

累计见到牌数1张关键牌 至少见到1张2张关键牌 至少见到1张
5张16.67%31.03%
8张26.67%46.90%
10张33.33%56.32%

计算方法：仅有1张时，命中率为n÷30；有2张时，用1减去“2张都落在未见到的30−n张中”的概率。例如见到8张时，结果为1−(22×21)÷(30×29)，约46.90%。

策划含义：加入第二张关键牌，提升的不只是卡牌数量，而是策略启动的稳定性。检索、发现与生成机制同样会改变稳定性，但必须按各自实际卡池和规则重新计算，不能直接套用这张表。

评估一套牌需要哪些指标

维度应观察的指标解释限制
强度按分段和对手分层的胜率不能用全体均值代表高手环境
稳定性启动回合分布、关键牌获得率平均启动回合会掩盖极早爆发
环境影响出场率、对局矩阵、策略覆盖热门可能来自新鲜感与易用性
体验失败前反制机会、极端爆发频率胜率接近50%也可能体验很差

演算为方法展示；没有真实对局样本时，不为当前环境的卡组排名或强弱程度下定量结论。

04 近期平衡案例 数值增强为何削弱体系

官方改动

36.4.2中，阿迦玛甘从8/9改为9/9；恐怖海兽从9/6改为8/8；震地雷龙从9费9/9改为8费8/8。官方解释：通过这些变更，移除绍克发现池中的即时高爆发选项，并加入节奏较慢的替代选项，保留体系特色。国服36.4.2说明

因果链拆解

攻击力调整 → 是否符合发现池条件改变 → 可获得的后续卡牌改变 → 爆发方式与反制窗口改变。

攻击力在这里同时具有“战斗属性”和“筛选条件”两种作用。只阅读卡面会把8攻到9攻理解为增强；把卡池关系加入分析后，才能看出该获取路径被切断。也应注意：移出某个发现池，不代表该卡在所有途径下都无法获得。

调整手段可能的收益要评估的代价
提高启动牌费用推迟整套组合，易于理解所有使用场景同时受到影响
降低终结伤害直接压低爆发上限可能损伤卡牌在其他体系中的功能
改变发现池组成针对特定获取路径改动不直观，需检查其他筛选关系

我的判断是，本次方案的价值在于更有针对性地改变组合兑现方式。但“更有针对性”不自动等于上线成功，仍需用补丁后的数据检查它是否保留了合理的玩法空间。

如果由我验收这次调整

  • 对照补丁前后相同分段、模式和地区的样本，记录绍克打出后的同回合伤害与终结比例；不能只看体系总胜率。
  • 同时看整套牌的出场率、对局胜率和持续使用率，确认不是通过让体系完全退出环境来降低爆发。
  • 检查其他使用阿迦玛甘、恐怖海兽和震地雷龙的套牌，以及其他按攻击力或费用筛选的生成效果。
  • 区分版本自然演变与改动效果；没有同条件对照时，只能报告趋势和关联，不能声称已证明因果。

此次还对食物链开放了特殊的限时全额返尘安排。同一官方公告 这说明平衡改动还会影响收藏投入；调整卡牌与解释资源补偿，应作为同一发布流程考虑。该公告所述两周期限不应在本案例日期被当作仍可领取的攻略。

05 资源经济与职业系列定价

资源循环

对局与任务推进成长，奖励路线提供金币、卡牌包等资源；玩家再通过获取卡牌、制作目标卡牌和调整构筑，扩大玩法选择。当前奖励路线同时存在免费奖励、付费内容和经验加成，且部分奖励卡不能分解。奖励路线官方说明

因此，经济模型必须区分“可转为制作资源的卡牌”和“只能使用或收藏的卡牌”。把所有奖励都按同一种奥术之尘价值折算，会高估实际可支配资源。

职业系列的可核算比较

以8月上线的“艾泽拉斯头号通缉”为例：普通单职业系列1200金币，普通四职业合集2500金币，并带额外内容。以下只比较金币标价，不给赠品估价，不假定每张卡都有实战需求。官方定价

玩家需要的职业数分别购买成本全合集成本只按金币看
1个12002500单买少花1300
2个24002500多100可获得另两个系列及赠品
3个36002500合集少花1100
4个48002500合集少花2300

四份单买与合集相比，合集标价低约47.9%。这只是标价差，不是全体玩家获得47.9%的实际收益。若额外职业完全不玩，多买仍然是额外支出；已经拥有部分卡牌时，还要按实际缺失量比较。

设计判断

单职业选项让目标明确的玩家获得确定内容；合集用较低的边际成本鼓励跨职业尝试。潜在问题是玩家容易把“每份平均便宜”误认为“最适合自己的投入”。合理的界面应显示能补齐的内容，而不只展示总卡数。

奖励路线还可以检验边际产出：官方表中76级与77级均奖励100金币，后者新增经验需求2500，对应这一段每1000经验40金币；不代表整条路线都具有相同兑换率。官方等级表

适合监测的指标：目标卡组补齐时间、购买后新卡实际使用率、跨职业尝试率，以及低收藏玩家的资源缺口。资源获取变快与收入变化都需验证，不能由定价表直接推导。

06 黑市活动的产出 消耗与结束机制

已知规则

国服黑市安排在9月16日至10月14日。玩家通过排名模式获得血石，兑换卡包和外观，商品价格会变化；10月7日起停止产出，最后一周仍可消费并存在议价机会，活动货币不跨期保留。36.6黑市说明

这个系统在引导什么行为

我的推断是：排名对局连接货币产出，奖励目标提供参与动力，价格变化提供再次查看的理由；停止产出后保留兑换窗口，使最后阶段从积攒转向消费。它们有利于形成阶段目标，但也可能带来错过奖励的压力。

设计环节预期作用需要验证的风险
排名对局产出将活动参与导向核心玩法是否出现刷取或异常早退
动态价格增加关注和选择时机玩家是否因涨价产生后悔
独立限时货币控制活动内的资源规模规则解释和余额管理成本
末周仅消费提供集中兑换阶段用户是否误以为还能继续赚取

数值方案必须先知道哪些参数

至少需要明确：各类有效对局的产出、是否有上限、物品库存、价格区间、议价机制和不同参与强度玩家的余额分布。公告未提供完整参数，不能据此宣称“每日几局必拿全部奖励”。

假设演算：某目标当前价格900血石，每个活跃日获得150血石，初始余额为0，无价格变化，则需要6个活跃日。若价格涨到1200，则需要8日。这组数字仅展示敏感性，不是活动真实价格或真实产量。

如按此模型设计，应先确定普通参与玩家的可达目标，再反推产出与价格。新增奖励不能只按理想全勤用户配置，否则较晚进入活动的玩家可能无法形成可实现的目标。

验收重点

按进入活动的日期及参与强度分组，观察首件兑换时间、至少兑换一件的用户比例、到期未消费余额和异常对局占比。剩余货币比例需同时检查绝对余额：少量不可消费尾数与大额忘记兑换，应采用不同处理方式。

我的优先建议是清楚区分“产出结束”和“兑换结束”两个倒计时，并显示已选目标的当前差额。该建议是否属于新增功能，需要先核查当前客户端界面。

07 移动端提案 卡组变更说明与修复入口

问题假设与目标

假设回归玩家打开手机时，看到收藏卡牌变化，却不清楚自己的卡组为什么变弱、是否仍合法、该投入哪些资源。连续切换公告、收藏和卡组界面可能加重理解负担。该痛点需通过实机观察验证，不能直接视为现有产品缺陷。

提案是在卡组详情增加轻量的“本次更新影响”入口，帮助玩家理解变动并做出选择。它不在对战中推荐最优行动；多端共用同一规则数据，移动端优先验证展示方式。

最小可用流程

打开受影响卡组 → 查看直接与关联变化 → 预览替换草稿 → 检查资源缺口 → 用户主动保存。

状态页面必须解释的信息操作规则
直接变化哪张牌的费用、属性或文本改变展示旧值与新值及版本号
关联变化哪个发现池或组合路径受到影响仅呈现已维护的明确关联
替换预览缺失卡牌、用途和预估资源先生成草稿，不自动制作
规则失效数据与当前版本不一致暂停推荐，保留变更说明

关联说明示例：“这条发现路径已无法获得阿迦玛甘，原有爆发组合可能受影响。”该句解释规则变化，不给出未经验证的胜率跌幅。

范围与依赖

第一版只覆盖有官方说明、可人工维护的少量关联关系。由策划维护版本、受影响卡牌ID、关系类型、解释和失效版本；客户端按用户卡组匹配；服务端校验合法性与拥有情况。使用版本配置与灰度开关，错误时可以关闭推荐。

与其先建设覆盖全卡池的智能推荐，不如先验证“清晰解释变动”是否改善玩家恢复对局的效率。若当前客户端已有类似能力，则将提案改为文案层级、关联覆盖与移动展示优化，避免重复建设。

手机端验收点

长卡名、长关键词与不同语言应完整展示；滚动阅读不遮挡确认按钮；弱网返回不能重复扣资源；切后台再回来应保留草稿，并重新检查版本。把误触、断线、渲染延迟分别记录，不能把所有失败都归为用户不会操作。

08 验证计划与优先级

先确认问题存在

先做6至8名移动端回归玩家的形成性测试，观察“识别受影响卡组、解释变化、生成可用草稿”三个任务。记录完成时间、错误理解和放弃位置。该规模只用于发现明显问题，不能推算总体比例或留存提升。

若用户本来能顺畅完成，则降低提案优先级；若主要障碍来自卡牌短缺而非理解不足，应转向资源或回归扶持设计。

再进行有明确口径的实验

目标人群定义为“连续30天无对局后回归，使用移动端，且拥有受该补丁影响的合法卡组”的账号。30天是提案分组定义，可按实际业务口径调整。按账号随机分组，避免同一用户多设备进入不同组。

埋点包括影响入口曝光、详情查看、草稿创建、保存、制作确认和对局完成；附版本号、卡组谱系ID、分组、设备档位与时间。统计去重和“有效对局”规则要预先确定。

实验判断

预先设定最小有意义提升和观察窗口，根据基线及流量估算样本。假设基线40%、希望检测到43%，在独立样本近似下，双侧5%显著性、80%功效约需每组4200人；真实规划仍需考虑重复行为、分层和流失。

控制组保留既有体验，实验组增加说明入口；跨越新补丁时分层或重新开始，不把版本变化混进功能效果。主要指标改善、护栏无实质恶化且样本充分，才考虑扩大覆盖。主指标没有改善时，先检查曝光和理解链路，不据次级指标宣布成功。

优先级：先做变更解释和版本正确性，再考虑替换草稿；全卡池自动推荐后置。实现成本主要在规则关系维护与数据准确性，而不只是增加一个页面。

09 面试讲述与追问准备

三分钟讲述参考

“我选择炉石手游，重点研究系统和数值如何一起影响玩家体验。我的结论是，平衡要看卡牌之间的关系，经济要看玩家能否形成可用卡组，移动端则要降低理解这些变化的成本。

近期36.4.2有个典型案例：阿迦玛甘攻击力从8提高到9，却因为不再进入绍克的发现池，削弱了食物链相关爆发。这让我看到，同一个数值可能同时是战斗属性和系统筛选条件。验收时既要观察爆发频率，也要确认原体系仍然有可玩的空间。

我还比较了职业系列的定价。单职业1200金币，合集2500金币。只玩一个职业时单买更省，准备玩两个职业时合集只多100金币。它鼓励拓展玩法，但不能把平均单价下降直接说成每个玩家都更划算。

基于这些变化，我提出卡组变更说明入口。先让回归玩家理解自己的卡组发生了什么，再选择是否替换。先验证痛点，再用24小时恢复对局率和误操作等护栏评估。这里的优化效果是待验证假设，我没有把方案写成已上线成果。”

五个常见追问

为什么不能只按胜率削弱？ 胜率受分段、熟练度和对手分布影响。平均胜率正常的卡组，也可能在少数场景制造极端爆发；要同时看对局矩阵、启动回合分布和反制机会。

为什么不直接多送卡？ 先分清资源不足与理解不足。对缺牌用户，解释不能替代资源；对有牌但不知如何调整的回归玩家，增加卡牌也未必解决问题。需要按障碍分组。

付费是否只卖外观？ 不能这样概括。卡牌获取、奖励路线加速与外观属于不同价值；战棋还有自身的通行证权益，应分别评估，避免把一个模式的商业化结论推广到全部玩法。

你怎样证明提案有效？ 目前不能证明。公开公告支持规则事实，演算展示分析方法；访谈和实验方案说明下一步如何验证。只有真实样本与结果才能支持效果结论。

你作为实习生可以交付什么？ 版本变化清单、关联规则配置表、资源成本比较、原型说明、埋点字典、测试用例和分析报告；卡牌最终数值与全量发布应由团队评审。

讲述时将“我研究了、我提出了”用于本案例；没有实际做过的访谈、实机记录和实验，不应表述成已完成工作。
